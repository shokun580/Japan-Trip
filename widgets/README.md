# Japan Trip บนหน้าโฮม iPhone

มีสองอย่างที่ทำได้ แยกกัน ทำอย่างใดอย่างหนึ่งหรือทั้งสองก็ได้

## 1. เพิ่มเว็บไว้หน้าโฮม (เปิดเหมือนแอป)

1. เปิด https://japan26.ast0miq.com ใน Safari
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) → "เพิ่มไปยังหน้าจอโฮม" → "เพิ่ม"
3. เปิดจากไอคอนบนหน้าโฮม แล้วเลือกชื่อตัวเองอีกครั้ง (โชกุนต้องใส่ PIN อีกรอบ)

ที่ต้องเลือกชื่อใหม่ เพราะ iPhone เก็บการเข้าระบบของแอปบนหน้าโฮมแยกจาก Safari
เลือกครั้งเดียวแล้วจะจำไว้

## 2. Widget บนหน้าโฮม (ผ่านแอป Scriptable)

iPhone ไม่ยอมให้เว็บสร้าง widget เอง จึงใช้แอปฟรีชื่อ Scriptable มาวาดแทน
widget ขนาดกลางจะแสดง

- วันนี้เป็นวันที่เท่าไรของทริปและอยู่เมืองไหน (ก่อนทริปจะเป็นชื่อทริป)
- นับถอยหลังเที่ยวบินถัดไป (ก่อนทริปจะเป็นตัวใหญ่ตรงกลาง)
- กิจกรรมถัดไปพร้อมเวลา (เวลาญี่ปุ่น)
- ปุ่ม "นำทางไปที่พัก" เปิด Google Maps ไปโรงแรมของคนนั้น

แตะที่ปุ่มจะเปิดแผนที่ แตะส่วนอื่นของ widget จะเปิดเว็บ
ถ้าไม่มีสัญญาณ widget จะแสดงข้อมูลล่าสุดที่โหลดไว้ และมีคำว่า "ออฟไลน์" ต่อท้าย

### ตั้งค่าครั้งแรก (โชกุนทำครั้งเดียว)

widget อ่านข้อมูลผ่านรหัสลับ `WIDGET_TOKEN` แทนการเลือกชื่อ

1. สร้างรหัสในเทอร์มินัล: `openssl rand -hex 32`
2. ใส่ใน Vercel → Project → Settings → Environment Variables ชื่อ `WIDGET_TOKEN` (Production) แล้ว redeploy
3. ส่งรหัสนี้ให้คนในทริปทางแชตส่วนตัว อย่าใส่ลงในโค้ดหรือ GitHub เพราะ repo นี้เป็นสาธารณะ

ถ้ารหัสหลุด เปลี่ยนค่าใน Vercel แล้ว redeploy widget เดิมจะขึ้นว่า token ไม่ถูกต้อง
จนกว่าจะใส่รหัสใหม่

### ติดตั้งบน iPhone แต่ละเครื่อง

1. ติดตั้ง Scriptable จาก App Store (ฟรี)
2. เปิดไฟล์ https://raw.githubusercontent.com/shokun580/Japan-Trip/main/widgets/trip-widget.js ใน Safari แตะค้างที่ข้อความ → เลือกทั้งหมด → คัดลอก
3. เปิด Scriptable กด + มุมขวาบน วางโค้ดลงไป แล้วแตะชื่อด้านบนเปลี่ยนเป็น `Japan Trip`
4. หาบรรทัด `const TOKEN = "ใส่ WIDGET_TOKEN ตรงนี้";` แล้วแทนข้อความในเครื่องหมายคำพูดด้วยรหัสที่ได้จากโชกุน
5. กด Done แล้วกด ▶ ทดลองรัน ควรเห็นตัวอย่าง widget ขึ้นมา
6. กลับหน้าโฮม แตะค้างที่ที่ว่าง → แก้ไข (หรือ +) → เพิ่ม widget → ค้นหา Scriptable → เลือกขนาดกลาง → เพิ่ม widget
7. แตะค้างที่ widget → แก้ไข widget แล้วตั้ง
   - Script: `Japan Trip`
   - Parameter: key ของตัวเองจากตารางด้านล่าง (เช่น `may`)

| ชื่อ | Parameter |
| --- | --- |
| โชกุน | `shokun` |
| เมย์ | `may` |
| แม่โชกุน | `mom-shokun` |
| แม่เมย์ | `mom-may` |
| พอร์ช | `porsche` |
| โอ๊ค | `oak` |
| ชานนท์ | `chanon` |
| พ่อโชกุน | `dad-shokun` |
| จีวร | `jeewon` |

Parameter เลือกแค่ว่าจะแสดงโรงแรมของใคร ถ้าเว้นว่างจะใช้ค่า `PERSON` ในสคริปต์ (`shokun`)

### เมื่อมีปัญหา

- ขึ้นว่า "token ไม่ถูกต้อง": รหัสในบรรทัด `TOKEN` ไม่ตรงกับใน Vercel หรือยังไม่ได้ redeploy
- ขึ้นว่า "ไม่รู้จักชื่อนี้": Parameter สะกดไม่ตรงกับตาราง
- ข้อมูลไม่อัปเดตทันที: iPhone เป็นคนเลือกเวลารีเฟรช widget เอง ปกติทุก 15 นาทีขึ้นไป
